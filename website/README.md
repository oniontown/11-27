# 智慧行程推薦網站規格

1. 讀者從週報或影片入口進入需求表單。
2. 表單收集客群、旅行日期、出發地、預算、偏好與必要限制。若需回覆，收集旅客選擇的聯絡方式，並在送出前說明用途並取得同意。
3. 依日期、預算及必要限制篩選候選行程，再依偏好排序。缺少必填欄位時提示補填。沒有符合結果時，說明限制並請旅客調整偏好或申請人工協助。
4. 推薦草稿包含提案編號、週次、偏好摘要、行程及推薦理由、來源及查詢日期、預算假設、待確認事項。成功送出後顯示確認訊息，交由旅行社覆核後回覆。
5. 機密由伺服器端管理。只用模擬資料測試，並清楚標示。

交接給驗收員時，附週次、測試網址、可重現的模擬案例、狀態及待確認事項。
