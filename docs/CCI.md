# CCI｜旅行社獲客網站

本文件依課程定義規劃第一版網站。內容起點為 2026-W48 台灣旅遊情報週報，景點與活動資料查詢日為 2026-11-27（台灣時間）。 [台灣旅遊情報週報](weekly-report.md) · [逐筆來源](../research/sources.md)

| 項目 | 課程定義 | 如何落實 |
| --- | --- | --- |
| Core 核心 | 幫助旅客快速找到適合自己的旅遊行程。 | 從週報進入同一個需求表單，一次看見最多三個方案及推薦理由。 |
| Clear 明確 | 可選旅遊對象、預算、天數、旅遊風格。 | 選親子、情侶或熟齡，填每人新台幣預算上限與出遊天數，可選一種以上風格或不拘。指定日期與必要動線可用來檢查候選行程。 |
| Issue 問題 | 行程太多、比較困難、不知道如何選擇。 | 用一致的卡片欄位比較天數、每人預算、行程亮點與待確認事項。無符合方案時，保留原條件並指出可調整的選項。 |

## 首版成果

旅客能完成「看週報、選需求、看推薦、複製諮詢摘要」。用親子、情侶、熟齡各一個案例驗收，並加測無結果、缺少估價與資料過期。預算口徑、排序、狀態與驗收詳見 [PRD](PRD.md)。
