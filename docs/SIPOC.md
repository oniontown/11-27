# SIPOC｜旅行社獲客網站

流程起於旅客選擇需求，止於網站展示行程提案並提供可複製的諮詢內容。旅客自行使用旅行社既有窗口聯繫。

| SIPOC | 課程定義 | 首版交付與責任 |
| --- | --- | --- |
| Supplier 供應者 | 旅行社、觀光署、活動主辦單位。 | 旅行社整理方案、費用口徑與適用條件。觀光署提供景點與活動公開資料。主辦單位提供展期、異動及指定日資訊。 |
| Input 輸入 | 旅遊資料、客戶偏好、行程條件。 | 匯入週報對應景點 ID、來源、查詢日期及狀態。旅客輸入對象、每人預算、天數及風格，可補出發地、日期與必要限制。 |
| Process 流程 | 選擇需求 → 比對方案 → 生成推薦。 | 驗證輸入後，以客群、天數、預算、日期及必要限制篩選，再依風格排序，顯示理由、來源及待確認條件。 |
| Output 輸出 | 旅遊提案、行程介紹、諮詢內容。 | 顯示最多三個符合方案與行程介紹，或提供調整條件及人工諮詢的入口。諮詢摘要包含已選條件及待確認事項。 |
| Customer 顧客 | 親子、情侶、熟齡旅客。 | 親子留意年齡與推車需求，情侶可選水岸或光影，熟齡可提出步行、休息及輔具需求。 |

## 交接與例外

- 旅遊研究員交付景點來源、查詢日、活動日期與待確認清單。旅行社補齊可比較的方案估價、包含項目與必要動線，網站工程師才將方案納入對應條件的正式推薦。
- 指定日條件、預算或必要動線無法核實時，轉入候選或人工確認流程。需求選擇保留給旅客編輯，網站不會自動更改。
- 驗收員核對三類客群、無結果、過期狀態與複製諮詢摘要。旅客自行聯絡後，由旅行社複查並回覆。
